Kria Package Manager

Coming soon   KPM will bring first-class package management to the Kria ecosystem.

What is KPM?

KPM (Kria Package Manager) is the planned package and dependency system for Kria. Today, multi-file projects use relative file imports. KPM will add registry-based packages so you can depend on shared libraries without copying source files.

Today vs. planned

Feature Available now Planned (KPM)
File imports import math from "./math.krx" Same, plus resolution from package cache
Package imports — import pkg (no path)
Dependency manifest — kria.toml or similar
Registry / publish — Share packages with the community

Current module system

Until KPM ships, use relative imports between .krx files:

// math.krx
export fn add(a, b) {
    return a + b
}

// main.krx
import math from "./math.krx"
print(math.add(2, 3))
  • Only export fn symbols are visible to other files
  • Import paths must be relative (./, ../)
  • Circular imports are rejected at compile time

Roadmap
