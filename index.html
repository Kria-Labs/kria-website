Kria · krx

Kria Programming Language

A dynamically typed language implemented in Rust, with a bytecode virtual machine. It supports 64-bit integers and double-precision floats, functions, closures, and a persistent interactive REPL. Write .krx files or explore the language.

Download Kria Read the docs

Features

Dynamic Numeric Types

Use 64-bit integers and double-precision floats, including decimal and scientific-notation literals.

Interactive REPL

Run kria with no arguments. Persistent session, multi-line input, and command history.

Functions & Closures

Named functions, lambdas, and nested closures that can retain and update captured values.

Arrays & Objects

Mutable and immutable arrays, object literals, deep equality, and for-in iteration.

Modules

Multi-file projects with export fn and import alias from "./file.krx".

Quick example

fn greet(name) {
    return "Hello, " + name
}

set message = greet("Kria")
print(message)

Build from source (optional)

Choose this route only if you want to build Kria yourself. You will need the Rust toolchain; the Kria project uses the Rust 2021 edition.

1. Development build

cargo build

This creates a debug build. Useful for development and testing.

2. Release build (recommended)

cargo build --release

This creates an optimized release binary. The binary is located at target/release/kria.

3. Install to your system

For Linux / macOS:

./release/build.sh install

This builds Kria and installs it to ~/.kria/bin. Make sure this directory is in your PATH.

Run Kria

Interactive REPL

kria

Starts the interactive REPL where you can write and execute Kria code. Variables and functions persist until you exit or reset.

REPL commands:

  • :help — Show available commands
  • :quit or :exit — Exit the REPL
  • :reset — Clear all variables and functions

Check version

kria -v
# or
kria --version

Run a source file

kria test.krx

Execute a Kria program from a .krx file.

Platform-specific build and packaging

Windows

A Windows installer is available from the GitHub Releases page (check for newer assets). To create an installer from source, install NSIS. 

cargo build --release
cd release
makensis kria-setup.nsi
# Run the generated installer from release/

Linux / macOS

Check GitHub Releases for newer Linux/macOS binaries. No prebuilt Linux/macOS binary was listed when this page was checked, so use the source build to install to ~/.kria/bin: 

cd release
./build.sh install

Create a distributable archive:

./build.sh package

Creates kria-<version>-<os>-<arch>.tar.gz
