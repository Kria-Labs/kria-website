Build prerequisites

The GitHub Releases page provides ready-to-use builds when available. At the time this page was checked, the latest published release was 1.2.0 and included a Windows installer; no prebuilt Linux/macOS binary was listed. Check the release assets and notes for current availability. If a suitable build is available for your platform, you do not need to install Rust or compile the source. The source repository is at version 1.3.0, so its features may differ from the published release.

To build Kria yourself, you need the Rust toolchain. Kria is built using the Rust 2021 edition. Install Rust using rustup. 

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

Download or build Kria

Download a release (recommended)

Open Kria on GitHub Releases, choose a published release, and download an asset suitable for your operating system and architecture. Follow that release's notes to install or run it.

Build from source

If you prefer to build Kria yourself, clone the repository and build in release mode:

git clone https://github.com/Kria-Labs/kria-lang.git
cd kria-lang
cargo build --release

The compiled binary will be at target/release/kria (kria.exe on Windows). You can add it to your PATH or run it directly.

Your First Program

Create a file named hello.krx:

set x = 5
set y = 3
print(x + y)

Run it with:

# Linux / macOS
kria hello.krx

# Windows PowerShell
.\kria.exe .\hello.krx

Output: 8

Interactive REPL

Start the interactive Read-Eval-Print Loop with no arguments: 

kria

The REPL provides a persistent session where variables and functions stay in scope until you reset or exit.

Meta Commands

  • :help — Show available commands
  • :reset — Clear all variables and functions
  • :exit — Exit the REPL

Try this in the REPL:

set name = "Kria"
print(name)
fn greet(x) { return "Hello, " + x }
greet(name)
