What is Kria Playground?

Kria Playground brings the Kria interpreter to the web using WebAssembly. Write and execute Kria code instantly without installing anything.

Perfect for:

  • Learning Kria without setup
  • Sharing code snippets with others
  • Experimenting with language features
  • Teaching and demos

Features (Planned)

Live Editor

Write Kria code with syntax highlighting and instant feedback.

Real-time Output

See program output immediately as you type and run.

REPL Mode

Interactive prompt for experimenting with expressions and statements.

Code Sharing

Share code snippets via URL for collaboration and discussion.

Examples

Built-in examples and templates to get you started.

Offline Support

Works offline once loaded — no server required.
