About Kria

Built by Kria Labs — a language focused on clarity, performance, and approachable syntax.

Our mission

Kria is a custom programming language designed to be easy to learn and fast to run. We combine a readable, newline-based syntax with a performance-oriented bytecode VM that optimizes common patterns like counted loops and global arithmetic.

Whether you are prototyping in the REPL or building multi-file projects with modules, Kria aims to stay small, predictable, and fun to use.

Implementation

The Kria interpreter and compiler are written in Rust. The pipeline uses a recursive-descent parser, a flat bytecode format with a constant pool, and a stack-based virtual machine with call frames for functions and closures.

Design goals

  • Simple syntax — no semicolons, set for assignment, familiar control flow
  • Dynamic + strong typing — runtime types with predictable behavior
  • Performance — combined loop instructions and specialized global ops
  • Modularity — file-based modules today; KPM package manager planned
  • Developer experience — REPL with history, multi-line blocks, and meta commands
